# Component Details

## ESP8266
Wi-Fi-enabled microcontroller used to read sensor data, execute the fall-detection logic, and communicate with the Blynk IoT platform.

## ADXL345
A 3-axis digital accelerometer that measures acceleration along the X, Y, and Z axes. Its readings are used by the controller to identify motion patterns.

## Buzzer
Provides a local audible indication when the programmed logic detects a possible fall.

## Lithium-ion Battery
Provides portable power. Record the battery capacity, protection circuit, charging method, and voltage regulation used in the actual prototype.

## Blynk IoT
Provides remote monitoring and notification functionality through the ESP8266's Wi-Fi connection. Record the configured template, datastreams, and event name, but never publish authentication tokens.
